AI news for Data Products and Data Platforms

  1. 01
    ANZ moves a 1.7PB Hadoop estate to AWS in six months

    ANZ said on 17 November that its Enterprise Big Data platform, 1.7 petabytes across 300 million files, 142,000 tables, 4,500 automated workflows and 4,000 views, now runs on Amazon EMR after a six-month migration that used agentic AI, against an expected 18 months. iTnews reports the bank confirmed its 70% operating-cost figure covers tokenisation only, not the whole platform. ANZ newsroom · 2026-11-17

    A bank has put a number on agent-assisted migration time, which changes the estimate in any buy-versus-rebuild case for a legacy estate. The cost claim is narrower than the headline, so a business case should borrow the timeline and not the savings.

  2. 02
    Starburst gathers business definitions into one layer for agents

    Starburst announced Context Studio on 18 November. It harvests definitions from where they already live, including business catalogs, BI tools, metric stores, query history and existing data products, and applies them when an agent queries the data. It is in private preview, with public preview planned for January and general availability in the first quarter of 2027, and pricing not yet set. BigDATAwire, on the Starburst Context Studio launch · 2026-11-18

    This is a third approach to keeping an agent's answer consistent with the dashboard's: federate the definitions that already exist instead of rebuilding them in one semantic model. A platform team choosing where metric definitions live now has that option to weigh, though Starburst has published no accuracy figures yet.

  3. 03
    NATO opens a marketplace to buy commercial space data

    NATO and the US Space Force launched the Global Data Marketplace on 17 November, built on Bluestaq's procurement platform. 222 companies from 17 Allied nations have joined, and first orders are expected before the end of 2026, with the NATO Communications and Information Agency acting as contracting authority. NATO · 2026-11-17

    A large buyer has chosen a single procurement marketplace over bilateral contracts with each data supplier. That is a test case for anyone weighing how external data supply should be bought, catalogued and governed: one storefront with standard terms, or one negotiation per provider.

  4. 04
    UK regulators publish AI cyber practices and consult

    The Bank of England, PRA and FCA published effective practices on 19 November for managing cyber risk where AI creates new risks or amplifies existing ones, alongside consultation CP17/26 on cyber risk and resilience management, which closes on 26 February 2027. The AI practices are not formal expectations and can be applied in proportion to a firm's size and risk profile. Bank of England, Prudential Regulation Authority · 2026-11-19

    Update you saw this on 2026-11-13 The regulators have now published the AI effective practices and opened consultation CP17/26, closing 26 February 2027.

    UK financial firms now have a written reference for how AI changes cyber risk. Any agent with access to governed data, Genie on a gold layer included, should be checked against it before February, while the consultation is still open to comment.

  5. 05
    Snowflake converts Tableau workbooks into Streamlit apps

    A preview skill for Snowflake's Cortex Code agent, listed in the release notes on 12 November, converts an exported Tableau workbook or data source into a multipage Streamlit in Snowflake app, one page per dashboard. It runs first on synthetic data and is then pointed at real tables, and a connected Tableau MCP server can find and download the workbook for it. Snowflake documentation · 2026-11-12

    A data platform vendor is now using an agent to pull dashboards off a BI tool and onto its own compute. Any BI renewal case has to account for how cheap that exit has become, and for whether dashboards should run on the platform at all.

AI-ready vs analytical-ready data

  1. 01
    Data contracts as the metadata agents would otherwise guess

    Simon Harrer, who sits on the Open Data Contract Standard's technical steering committee, argues that data contracts will become for data what OpenAPI is for REST APIs. ODCS is governed at the Linux Foundation, and its 3.2 release added a context block that tells agents how the data is meant to be used. BARC notes the standard is declarative only: a constraint in a contract does nothing unless the systems involved enforce it. Simon Harrer, martinfowler.com · 2026-11-18

    This makes the contract on a gold-layer table the place where agent usage rules are written down, rather than a prompt or a wiki page. Enforcement still has to come from the platform's own access controls, and the roadmap should plan for both.

  2. 02
    Atlan open-sources a standard for agent registries

    Atlan released ai-registry on 30 October, an open spec for describing a team's agents, what they use and who owns them. Registries can be stored on infrastructure a team already owns, such as a Git repo or an object storage bucket, and an aireg CLI installs pinned, verified skills and agents into coding tools. Its own speaker called the project very early. Atlan, open source · 2026-10-30

    Agents are starting to need the same catalog entries as datasets: an owner, dependencies and a version. A governance roadmap that already registers data products can plan for agents as the next asset type, without committing to a spec this young.

case study · AWS Big Data Blog
How ANZ Institutional Division built a federated data platform for domain data products

ANZ's institutional bank used to have data handled by central teams, with each part of the business keeping its own copy. It moved to a model where each business area owns its data and publishes it as a product, on top of a shared self-service platform. Each area acts as one node in a wider bank-wide network, and it decides whether a product goes into the division's catalog for everyone or stays visible only to its own users. Shared risk and governance standards apply to every node, so having separate owners does not mean having separate rules.

For the roadmap This is a worked answer from a bank on where modelling authority sits. Domains own and publish their products, the platform supplies the catalog and tooling, and governance is the one thing that stays central. It gives a foundation-phase roadmap a concrete next step: decide which datasets count as published products, and which are private to the team that owns them.
