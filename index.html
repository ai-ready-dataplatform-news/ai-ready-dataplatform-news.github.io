AI news for Data Products and Data Platforms

  1. 01
    Only 13% of CIOs report significant value from AI

    Gartner's survey of 2,002 technology leaders, released at its Orlando symposium on 19 October, found 13% of CIOs say AI has delivered significant or transformational value, one use case in five succeeds, and 58% face more pressure to show cost improvement from AI. Business Wire · 2026-10-19

    The organisations Gartner rates as leaders are 2.3 times likelier to have pilot-to-production rules, which favours scoring a foundation-phase platform on governed, reusable outputs rather than on the number of AI pilots it supports.

  2. 02
    Databricks fully supports its agent for rewriting legacy SQL

    On 15 October Databricks made its Genie Code-powered agentic code converter generally available for SQL, translating T-SQL, Snowflake, Redshift, Oracle, BigQuery and Teradata SQL into Databricks SQL inside a migration project that validates output; other targets stay in beta. Databricks release notes · 2026-10-15

    A supported, validating converter cuts the cost of moving legacy warehouse logic, so the estimate for retiring a Redshift or Teradata estate onto the lakehouse is due for a refresh.

  3. 03
    Neo4j launches a context engine for enterprise agents

    Neo4j announced the Context Engine on 20 October in private preview, a shared knowledge layer built on a predefined six-layer graph that maps an organisation, its processes, its data and its AI assets so agents can reason over them with memory. Neo4j · 2026-10-20

    Graph vendors now compete with catalogs and semantic layers for the context agents read, which adds a contender to any decision on where business definitions for agentic access should live.

  4. 04
    Salesforce buys Loops to explain metric changes in Tableau

    Salesforce signed a definitive agreement on 12 October to acquire Loops, whose models watch business KPIs, flag anomalies and explain why a metric moved, folding the technology into Tableau with closing expected in early November and no price disclosed. Pulse 2.0 · 2026-10-12

    BI vendors are buying the layer that explains metric movements, which makes governed metric definitions a precondition for trusting the explanation and a factor in any analytics-layer renewal.

  5. 05
    Google pays more than 400 publications to license AI content

    Google said on 15 October that more than 400 publications, now including CNN, the Financial Times, Axios and Forbes, are paid to supply enhanced content for AI features in Google News, with attribution and links back, and that payment does not depend on how much content contributes to an answer. The Next Web · 2026-10-15

    A flat licence for delivery rather than pay-per-use attribution is a pricing model commercial data product teams will be measured against when selling data into AI answers.

AI-ready vs analytical-ready data

  1. 01
    Outside engines can now write to Unity Catalog managed tables

    From 13 October external Apache Spark clients can create and write Unity Catalog managed Delta tables at general availability, given catalog commits are enabled, and external engines can query Unity Catalog views over Delta tables through the Unity REST API. Azure Databricks release notes · 2026-10-13

    If outside engines write into the governed catalog rather than beside it, the gold layer stays the single source for every consumer, but write access becomes a contract to define rather than an exception to block.

  2. 02
    Snowflake's catalog reaches into Power BI, Tableau and dbt

    Horizon Context entered preview on 12 October, connecting Horizon Catalog to 18 external sources including Power BI, Tableau, dbt and PostgreSQL, with column-level lineage across them and the ability to edit descriptions and apply tags to external dashboards. Snowflake documentation · 2026-10-12

    Tagging dashboards in the warehouse catalog puts the warehouse vendor in the metadata seat a standalone catalog usually holds, which is a buy-versus-build question for any team that already pays for one.

  3. 03
    Genie One can now run code under the user's permissions

    Since 9 October Genie One can run code in an isolated serverless sandbox, in public preview, under the user's existing Unity Catalog permissions; it checks the code matches the request first, declines unmatched code in scheduled tasks, and bills it as sandbox usage. Databricks documentation · 2026-10-09

    Conversational access that goes beyond SQL still inherits catalog permissions, but it adds a compute line and a class of answer no metric definition governs, both worth settling before Genie access widens.

Lessons from a career in platform product management

A platform team builds things other teams use, so its customers are colleagues and its value shows up in someone else's results. That makes it easy to measure only how much faster or cheaper things got, which reads as a cost to be cut. Teresa Wang, who leads enablement product at Bupa, argues for tying platform work to the business numbers it moves, such as retention or customer satisfaction, through goals shared with the teams that use it. Adoption and reliability still count, but as evidence for that story rather than the story itself.

For the roadmap It gives a foundation-phase platform a way to argue its value before adoption is large: name the business outcome each governed dataset serves, set it as a shared goal with the consuming team, and report time to onboard and reliability as supporting measures.
