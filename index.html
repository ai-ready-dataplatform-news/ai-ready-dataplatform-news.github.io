AI news for Data Products and Data Platforms

  1. 01
    Databricks opens its pipeline-fixing agent to public beta

    Genie ZeroOps went to public beta on 19 November. It is a background agent that monitors production jobs, pipelines and tables, investigates failures and proposes fixes for a team to verify before applying, and Databricks says it observed more than 80,000 real customer issues during the private preview. A workspace admin switches it on from the Previews page, and catching data quality issues relies on Databricks' data quality monitoring, which is billed separately. Databricks blog · 2026-11-19

    This puts a platform-native option on the observability side of buy versus build, next to a separate quality tool. The comparison should cover cost per governed dataset, since detection is billed on top, and who signs off a proposed fix before it reaches the gold layer.

  2. 02
    dbt puts its charts inside Claude and ChatGPT

    dbt Labs' November update, dated 17 November, puts dbt Charts into Claude and ChatGPT in beta through a single MCP connection, so users can work with their boards and warehouse from inside those apps. dbt's own benchmark puts token use 20% to 50% below building the same dashboards from scratch. The update also adds local unit tests in alpha and batch testing in dbt v2. dbt Labs blog · 2026-11-17

    The transformation layer is now offering a governed route from the chat window to the warehouse. That matters to anyone deciding what the transformation framework should standardise, because a definition built in dbt would then reach a chat answer without going through the BI tool.

  3. 03
    ThoughtSpot's November release caps API calls per Org

    ThoughtSpot Cloud 26.11.0.cl was scheduled for general availability on 24 November. It brings Spotter, the AI analyst, into embedded apps and onto Liveboards (Visual Embed SDK 1.54.0 or later), and lets personalised Liveboard views carry over from development to production. It also introduces a limit of 50 requests per second per Org on public REST endpoints for instances using Orgs, which ThoughtSpot flags as a change that affects upgrades. ThoughtSpot documentation, 26.11.0.cl release notes · 2026-11-24

    An agent or pipeline calling ThoughtSpot's REST API at machine speed will now hit a ceiling, so any plan for agentic consumption through the BI layer has to budget its call rate per Org, alongside the pricing.

AI-ready vs analytical-ready data

  1. 01
    Microsoft bundles Fabric IQ into one agent context layer

    At Ignite on 17 November, Microsoft grouped Work IQ, Fabric IQ, Foundry IQ and Web IQ into Microsoft IQ, a context layer for agents that is not sold on its own; each part bills through an existing meter, with Fabric IQ drawing on Fabric capacity. Fabric IQ links business data to metrics and meaning, and is being extended to Excel, Copilot, ChatGPT, Claude and GitHub Copilot. Sources disagree on which pieces are generally available and which, including the Fabric IQ ontologies and the third-party chat connectors, are still in preview. Windows Forum, on Microsoft IQ at Ignite 2026 · 2026-11-17

    Microsoft is making the Power BI semantic model the place where an agent's answer gets its meaning, which is one answer to keeping the agent and the dashboard in agreement. A team running Power BI next to a Databricks gold layer now has two candidate homes for its metric definitions, and should decide which one is authoritative before both drift.

podcast · Nexla podcast, episode 15
Agent Management: How Do You Govern AI You Didn't Build?

Most organisations will not build all of their AI agents themselves. They will buy them inside tools, switch them on in platforms, or find that teams have connected them without asking. Governing an agent you did not build means treating what it reads and what it produces the way you treat any other important data: someone owns it, it has agreed definitions, and it can be traced. The episode's argument is that the outputs of AI become data products in their own right, and that a shared semantic and context layer underneath is what keeps different agents saying the same thing.

For the roadmap This turns AI governance from a model problem into a platform one. A foundation-phase roadmap can extend the gold layer's existing ownership and definition rules to agent inputs and outputs, starting with Genie, before a second agent arrives with its own idea of what a metric means.
