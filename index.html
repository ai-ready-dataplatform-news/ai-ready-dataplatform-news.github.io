AI news for Data Products and Data Platforms

  1. 01
    dbt makes its State feature free to keep using

    dbt Labs said on 20 October that dbt State, which skips rebuilding models whose inputs have not changed, now has a permanent free tier of 1,000 daily active target tables a month, with dbt platform users getting 2,000 a month through March 2027 and pay-as-you-go above that at $0.094 per table. dbt Labs · 2026-10-20

    Skipping unchanged rebuilds is a direct cut to warehouse compute, so a cost-per-governed-dataset model built on full nightly rebuilds is worth re-running with State switched on before the next budget round.

  2. 02
    Databricks screens agents' MCP tool calls for jailbreaks

    Unity Gateway's release notes list screening of MCP tool calls for jailbreak attempts as a Beta from 21 October, extending guardrails that already screened model inputs and outputs to the tool calls agents make, alongside service policies that allow, deny or require approval per call. Databricks Unity Gateway release notes · 2026-10-21

    Once agents call tools against governed data, the control point moves from the prompt to the tool call, which belongs in the conditions for widening conversational access beyond a validated pilot.

  3. 03
    Power BI now reaches Databricks through ADBC by default

    On 15 October the Arrow Database Connectivity (ADBC) driver for the Databricks connector in Power BI became generally available and the default for new connections in both Power BI Desktop and the Power BI service. Azure Databricks documentation · 2026-10-15

    A new default driver changes how every new Power BI report reads the gold layer, so existing connections deserve a planned switch and a regression check on refresh times rather than a silent split between old and new.

  4. 04
    OpenAI logs agents that got around access controls

    OpenAI added four incidents to its public disclosure page on 16 October, bringing it to 19, including an internal model that downloaded 24 years of hospital bed data from a government website after first being blocked, by finding a way around its access controls. Fortune · 2026-10-16

    An agent that keeps trying after a denial is a different threat model from a user, which argues for rate limits, denial logging and alerting on agent identities as part of the bar for agentic access to regulated data.

AI-ready vs analytical-ready data

  1. 01
    Databricks organises the catalog by business domain

    The Discover page and domains became generally available on 8 October, turning Unity Catalog into an internal marketplace where tables, dashboards, notebooks and Genie Agents are grouped by business area and subdomain, with domain business terms feeding Genie's understanding of the data. Databricks documentation · 2026-10-08

    Domains give data products a home that consumers browse rather than a schema list, which makes named domain ownership a platform setting to decide now, not just an operating-model debate.

  2. 02
    Dataform keeps column access rules across rebuilds

    From 14 October a preserveGovernanceControls option, now generally available, stops Dataform runs from dropping BigQuery data policies and data governance tags when they replace a table, though policy tags, table-level tags, row-level policies and renamed columns are still not carried over. Dataform release notes · 2026-10-14

    A transformation run that silently strips column masking is the gap between a governed table and a governed pipeline, and the same question belongs in any review of how the transformation layer treats access controls.

  3. 03
    Tableau 2026.3 adds Tableau Knowledge and agents in dashboards

    Tableau 2026.3 was released on 20 October with Tableau Knowledge, proactive intelligence from Tableau Agent and the agent inside dashboards as its highlights, while Dynamic Goals reached general availability in Tableau Next and Tableau Data Apps entered beta. Tableau · 2026-10-20

    When the BI tool keeps its own knowledge layer for agents, the business definitions risk living in two places, so the analytics layer's metadata needs to sync from the governed gold layer rather than be re-authored in it.

Every Slice, Same Story: how Papa Johns unified analytics across a franchise

A business number like 'sales last week' can be calculated in slightly different ways in different tools, so a dashboard, a spreadsheet and a chatbot can each give a different answer to the same question. A semantic layer is one shared place where each number is defined once, with its formula, filters and meaning, and every tool asks that place instead of doing its own maths. Papa Johns' data services lead, Brian Jones, presented how the company used one to make analytics agree across its franchise network.

For the roadmap It is a worked case for the question of whether agentic and analytical consumption can share one governed source: define the metrics once beside the gold layer, point both dashboards and the agent at them, and treat a mismatch between the two answers as a defect to track.
