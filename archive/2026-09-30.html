AI news for Data Products and Data Platforms

  1. 01
    Databricks Genie One MCP reaches general availability

    The Genie One MCP server is now generally available as system.ai.genie_one_mcp in Unity Gateway, letting Claude, ChatGPT, Cursor or custom agents query Genie with Unity Catalog permissions enforced on every request; the Beta endpoint is sunset on October 31, 2026. Databricks Blog · 2026-09-22

    A platform PM deciding whether agent access to a governed gold layer runs through the platform's own gateway now has a supported route, and a hard October 31 migration date for any Beta pilots.

  2. 02
    BigQuery continuous queries can now write to Iceberg tables

    BigQuery continuous queries can write their output rows into Apache Iceberg managed tables with a plain INSERT statement, so streaming results land directly in an open-format lakehouse; the destination table must already exist. Google Cloud release notes · 2026-09-28

    Gives a platform PM weighing open table formats a streaming path into Iceberg that needs no separate pipeline, which changes the build-versus-buy line for real-time ingestion.

  3. 03
    Snowflake lets Iceberg tables change partitioning without rewrites

    Partition evolution reached general availability on September 18 for Snowflake-managed Iceberg tables, allowing partition fields to be added, dropped or replaced after creation without rewriting existing data. Snowflake Documentation · 2026-09-18

    Removes a rewrite cost from the case against partitioning early, which matters to any platform team costing a table-layout decision before the query patterns are known.

  4. 04
    AWS study: AI approval processes are built for six-month programmes

    AWS's Reimagine 2026, drawn from interviews with 154 executives at 128 organisations, finds review processes designed for six-month IT programmes are slowing days-long AI work, and cites a survey where 24% have a documented responsible-AI approach and 10% a data governance strategy. Help Net Security · 2026-09-28

    Supplies numbers for the argument that governance has to be built into the platform path itself, rather than added as an approval queue in front of it.

AI-ready vs analytical-ready data

  1. 01
    Snowflake previews evaluation for AI function output quality

    Cortex AI Function Evaluation entered Public Preview on September 21, measuring output quality, cost and token usage of AI function calls against labeled datasets, in SQL or through Cortex AI Function Studio. Snowflake release notes (via fru.dev) · 2026-09-21

    Puts a repeatable baseline in the platform for the question of whether cleaner data improved a model's output, which is the feedback loop most readiness roadmaps lack.

  2. 02
    Snowflake AI_SUMMARIZE previews summarising documents and images

    Multimodal AI_SUMMARIZE entered Public Preview on September 14, taking text or a FILE reference to an image or document and returning a summary from one SQL function, with no custom chunking, parsing or model selection. Snowflake Documentation · 2026-09-14

    Treats documents and images as columns in the platform rather than a side pipeline, which shifts the readiness work to governing the files behind those references.

  3. 03
    Redshift adds Iceberg v3 with row lineage and deletion vectors

    Amazon Redshift can read and write Apache Iceberg v3 tables, adding default column values, row lineage pseudo-columns for incremental and CDC pipelines, and deletion vectors that replace v2 delete files for compliance-driven record removal. AWS What's New · 2026-08-31

    Row-level lineage in the table format itself gives a platform team a portable building block for incremental pipelines and deletion obligations, independent of any one catalog.

  4. 04
    Publicis Sapient: 73% use AI regularly, 10% say it is core

    A survey of 1,550 AI decision-makers fielded between April 29 and May 14 finds 73% say AI is used regularly or across most processes, only 10% say it is core to how the business operates, and 42% say the organisation is not set up to capture its value. Publicis Sapient · 2026-06-17

    Adds a large-sample reference point that adoption is not the same as readiness, useful when arguing what a platform in its foundation phase should be measured on.

Semantic Layer vs. Text-to-SQL: 2026 Benchmark Update

When someone asks a data question in plain English, an AI can write the database query itself, which is called text-to-SQL, or it can ask a rulebook of agreed metric definitions to build the query, which is what a semantic layer is. Left to guess from raw tables, the AI gets an insurance-style test right about 64.5% of the time, up from 32.7% in 2023. Given the rulebook, the same models score between 98% and 100% on the questions it covers. The bigger difference is how failure looks: without the rulebook a wrong answer looks plausible, and with it a wrong request comes back as an error.

For the roadmap Frames the decision of whether conversational access to a governed gold layer should route through modelled metrics or raw tables, with an error-not-wrong-answer failure mode as the deciding argument for anything an auditor might read.
