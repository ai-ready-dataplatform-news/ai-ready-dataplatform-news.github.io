AI news for Enterprise Data Platform Product Management

  1. 01
    Databricks Lakebase Goes GA, Genie Turns Pay-as-you-go

    Azure Databricks Lakebase, a managed serverless Postgres built for agentic workloads, reached general availability this month, and Genie Agents, Genie Code and Genie One moved to pay-as-you-go pricing with 150 free DBUs a month starting July 8. Microsoft Learn - Azure Databricks release notes · 2026-07

    Budget models for Genie-based agent pilots need a consumption forecast now, and Lakebase is a lakehouse-native operational database worth weighing before standing up a separate one.

  2. 02
    EU AI Act's High-Risk Deadline Lands in Two Days

    The EU AI Act's high-risk and transparency obligations take effect August 2 even though the Commission's proposed deferral to December 2027 remains unresolved, while a Senate-passed federal preemption bill could override US state AI laws if the House concurs. Cubbbix

    Platforms serving EU customers need lineage and risk-management evidence ready for August 2 regardless of how the deferral debate ends, waiting for clarity is not a compliance plan.

  3. 03
    MCP Moves to a Stateless Spec, SDKs Pass 1B Downloads

    The July 28 Model Context Protocol release replaces the bidirectional stateful core with a stateless request or response design, adding multi round-trip requests, header-based routing and cacheable list results, as Tier-1 SDKs cross a combined 1 billion downloads. Model Context Protocol Blog · 2026-07-28

    Any governed semantic layer exposing metrics to agents over MCP needs an integration review before the next SDK bump, the stateful assumptions it was built on just changed.

  4. 04
    Agentic AI Is Scaling Faster Than Its Governance

    Domino Data Lab's survey of 639 enterprise AI leaders found 57% still report AI ROI failing to outpace spend, and only 43% run agentic AI in governed production even as expanding agent use ranks as the top 2026 priority. Computer Weekly · 2026-07-22

    A roadmap that expands agentic use without funding governance at the same pace is repeating the exact failure this survey documents, budget both together or expect the same ROI gap next year.

  5. 05
    Iceberg and Polaris Converge on Catalog-Level Access Control

    The July 21-29 lakehouse community update reports Iceberg and Polaris arriving independently at the same conclusion: the catalog is the only component that sees every engine's request, making it the one place access control can be enforced consistently. Apache Data Lakehouse Weekly · 2026-07-29

    Weigh this convergence heavily in any buy-vs-build catalog decision, a catalog that can't centralize access control across every query engine becomes the governance gap rather than the governance layer.
