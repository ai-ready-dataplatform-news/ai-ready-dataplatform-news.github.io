AI news for Enterprise Data Platform Product Management

  1. 01
    BigQuery Security center reaches general availability

    Google made the BigQuery Security center generally available on 30 September, a console view for analysing a data security profile and managing row- and column-level security policies, governance tags and policy tags. Google Cloud Documentation · 2026-09-30

    Puts access-policy authoring and a security posture view in one place, so a central governance team and domain owners can be weighed against a console that supports either.

  2. 02
    Microsoft Fabric adds condition-based policies in preview

    The September Fabric feature summary introduces Policies (Preview), stored in Policy Set items, that let admins control who can create item types, change workspace settings or share data externally, scoped by workspace, security group and sensitivity label. Microsoft Fabric Community Blog · 2026-10-01

    Shows central admins narrowing self-service by condition rather than switching features off tenant-wide, a pattern a platform PM can borrow when deciding where the governance bar sits on new datasets.

  3. 03
    Snowflake prices Cortex REST API below the SQL function

    Finout reports that Snowflake's Service Consumption Table, effective 30 September 2026, prices the Cortex REST API about 17% lower per token than the AI_COMPLETE SQL function for the same model. Finout · 2026-09-30

    Makes the call route a cost variable, so a platform PM building cost per governed dataset has to attribute AI spend by access path as well as by model.

AI-ready vs analytical-ready data

  1. 01
    Unity Catalog ABAC policies now attach at metastore level

    From 17 September a single ABAC policy, whether row filter, column mask, GRANT or DENY, can sit at the metastore level and apply to every catalog including ones created later (Beta). Databricks Release Notes · 2026-09-17

    A governed gold layer can inherit one organisation-wide masking rule instead of copying it per catalog, which moves the question to who owns the metastore-level rule.

  2. 02
    BigQuery pipelines gain metadata enrichment and quality scorecards

    Generally available on 1 October: BigQuery pipelines support automated metadata enrichment and Knowledge Catalog data quality scorecard integration, and the Data Engineering Agent can generate semantic metadata for pipeline assets. BigQuery Release Notes · 2026-10-01

    Metadata and quality scores produced inside the pipeline rather than after it make governed a build-time property, which bears on both time to onboard and governed coverage.

  3. 03
    FCA's Mills Review keeps existing rules, adds no AI rulebook

    The 147-page review published on 6 July gives the FCA Board seven recommendations and concludes that the Consumer Duty, Senior Managers Regime and operational resilience requirements remain sound for AI. Financial Conduct Authority · 2026-07-06

    Accountability for AI outputs lands on existing named-owner regimes, so a platform serving regulated firms is better served by lineage and ownership evidence than by waiting for an AI-specific standard.

podcast · Experiencing Data with Brian T. O'Neill · 2026-04-15
Product Usage Does Not = Value: Why 'Adoption' Metrics Are Misleading You

Counting how often people open a data product only tells you the number is not zero. A dashboard opened daily out of habit and one opened daily because it changes a decision look identical on a usage chart. The episode argues for asking users what they were trying to get done and whether the product got them there, and for using that as the baseline instead of logins.

For the roadmap Tests the argument that adoption is the wrong headline metric for a platform in its foundation phase: swap usage counts on the scorecard for a measured user outcome, such as time to a trusted answer.
