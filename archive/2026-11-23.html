AI news for Data Products and Data Platforms

  1. 01
    Tableau Studio reaches general availability as the new Desktop

    Tableau's November 2026 release (2026.3.1) makes Tableau Studio generally available. It is an agentic workspace built into Tableau Desktop, where an agent builds metrics, calculations, dashboards and Data Apps from governed data sources, and a headless External Client API lets scripts or outside agents do the authoring. The agentic features require a Creator licence on Tableau+, Cloud+ or Server+. Tableau Studio developer guide, release notes (2026.3.1) · 2026-11-17

    Agentic authoring on the BI side now carries a premium-tier licence. Anyone costing a consumption layer has to price agent access separately from seats, and decide whether agents should build on certified data sources only.

  2. 02
    Circana ships last week's retailer sales data every Monday

    Circana launched Day 1 Delivery on 18 November. Retailer point-of-sale data for 16 retailers and more than 1,000 US retailer market areas now arrives the Monday after the Sunday week close, a week sooner than before, using the same methodology as its Complete Market product. Total-market MULO+ reporting stays on its usual schedule, so the early figures can be reconciled against it later. Circana · 2026-11-18

    A data vendor has made freshness the thing it sells, and has shipped a provisional feed that is reconciled against the full one later. That is the pattern to borrow when an internal data product has to trade completeness for timeliness and still show consumers which number is final.

  3. 03
    Databricks sends value-ranked conversions to nine ad platforms

    On 19 November Databricks introduced CustomerLake Conversions. Brands can score conversions using purchase history, margin and predicted lifetime value held in the lakehouse, then send those signals to Amazon Ads, Google, LinkedIn, Meta, Microsoft Ads, Reddit, Snapchat, The Trade Desk and TikTok through Conversions API connectors, with campaign results returning through OpenSharing and Lakeflow Connect. No price, release date, performance figures or named customers were given. PPC Land, on the Databricks CustomerLake Conversions launch · 2026-11-19

    First-party data is now leaving the platform as a derived, model-scored signal rather than raw records, which raises a governance question for any regulated firm. Who signs off what a lifetime-value score reveals once it reaches an ad platform, given that the launch did not say how consent or hashing are handled?

AI-ready vs analytical-ready data

  1. 01
    Workday buys a semantic layer so agents and BI agree

    Workday announced on 18 November that it intends to acquire Honeydew, whose semantic compiler turns business definitions into governed queries. Workday plans to embed it in Workday Data Cloud so that AI agents and BI tools apply the same metric definitions to live data, such as the same day's ledger. Terms were not disclosed, and the deal is expected to close by 31 January 2027. Workday newsroom · 2026-11-18

    An application vendor is paying for the layer that keeps an agent's answer consistent with the dashboard's. That backs treating shared metric definitions as gold-layer infrastructure owned by the platform team, not something each consuming tool redefines. As TechRepublic notes, agreeing a formula does not make the underlying records correct.

What I learned from running a data mesh

In most companies one central data team owns all the data, and every other team waits in its queue. A data mesh hands each business area its own data to own and publish, like a set of small shops instead of one warehouse. Ben Watson describes making that switch over about 18 months. The biggest change was that the central team stopped owning data and started building the shared tools that let each area own its data safely. He recommends starting with one team that actually wants ownership, rather than forcing it on everyone at once.

For the roadmap It is a first-hand answer to where modelling authority should sit. The central team keeps the platform, the shared ingestion, testing and monitoring, and hands ownership to a willing pilot domain first. That gives a roadmap a sequence for decentralising without each domain rebuilding the foundations.
