AI news for Enterprise Data Platform Product Management

  1. 01
    Gartner: agentic AI costs to balloon fivefold by 2028

    Gartner warns agentic AI spending will grow roughly fivefold by 2028 as complex multi-step workflows multiply token consumption faster than per-token prices are falling. The Register · 2026-08-17

    Budget models built on today's per-token pricing trend understate agent-era spend — cost forecasts need a consumption-growth assumption, not just a price-decline one.

  2. 02
    OpenAI tests privacy-preserving misuse detection

    OpenAI is testing Private Safety Processing with early customers including Microsoft and Databricks, flagging misuse patterns across conversations from metadata alone while preserving zero-data-retention guarantees. TechCrunch · 2026-08-19

    A path is emerging to keep API traffic under strict zero-retention terms without giving up abuse monitoring — worth revisiting any data-residency exception negotiated purely to avoid retention.

  3. 03
    Iceberg v4 debates a Parquet-only manifest

    Steven Wu's proposal to make Iceberg v4 manifests Parquet-only drew early support from Anoop Johnson and Russell Spitzer, since Avro can't support projection reads on manifest stats. Apache Data Lakehouse Weekly · 2026-08-18

    Update you saw this on 2026-08-14 formal scoping has moved to a specific technical proposal — Parquet-only manifests — with early committer consensus forming

    The v4 scoping opened in mid-August is now converging on a concrete break from Avro — engines and tools that assume dual-format manifests should plan the migration now, not after the spec lands.

AI-ready vs analytical-ready data

course · DeepLearning.AI / Coursera
DeepLearning.AI Data Engineering Professional Certificate

Before any model or dashboard sees a number, something has to fetch it from wherever it lives, clean up the mess, and land it somewhere queryable — that's data engineering, and it's mostly plumbing, not magic. This course walks through that plumbing end to end: pulling data in, transforming it, storing it, and scheduling all of that to run itself. None of it is AI-specific, which is exactly the point — a model trained or grounded on data that came through sloppy plumbing inherits the sloppiness, no matter how good the model is.

For the roadmap Treat pipeline reliability as a prerequisite line item on any AI roadmap, not a shared-services assumption — a governance layer or semantic model built on top of ungoverned ingestion just moves the mess one layer up.
