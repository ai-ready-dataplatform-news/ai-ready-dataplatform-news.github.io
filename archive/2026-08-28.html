AI news for Enterprise Data Platform Product Management

  1. 01
    Databricks launches account-level Governance Hub

    Databricks shipped Governance Hub on 26 August, a single account-level view combining data governance coverage, AI usage and spend, and cost drivers with prioritized fix-it recommendations, alongside a new Tags page in beta for auditing tag coverage. Databricks Blog · 2026-08-26

    A built-in, estate-wide governance dashboard changes the buy-vs-build calculus for any bolt-on catalog or FinOps tool that was about to make the shortlist.

  2. 02
    CISA flags critical, exploited Oracle WebLogic flaw

    CISA added the maximum-severity CVE-2026-21962, an unauthenticated RCE in Oracle HTTP Server and the WebLogic Proxy plugin, to its Known Exploited Vulnerabilities catalog on 24 August and gave federal agencies a 72-hour patching deadline, warning it lets attackers create, delete or modify critical data. The Register · 2026-08-25

    Any pipeline sitting behind Oracle HTTP Server or WebLogic — a common front door for on-prem data integrations — needs a patch-status check this week, not at the next quarterly review.

  3. 03
    Amazon exits human-data labeling with Mechanical Turk

    Amazon announced on 26 August that Mechanical Turk will close September 30, taking SageMaker Ground Truth and Amazon Augmented AI down with it and ending Amazon's run in human-in-the-loop data-labeling infrastructure. Tech Times · 2026-08-26

    Any pipeline leaning on MTurk or Ground Truth for labeling or human review needs a migration plan before September 30, and it's a data point on how much vendor risk sits in unglamorous "utility" data-labeling tooling.

  4. 04
    Iceberg splits conformance tests into their own repo

    Apache Iceberg's community passed a vote this week to create apache/iceberg-verification, a standalone, language-neutral home for conformance fixtures that every implementation can run against, so no single client library owns the spec's test suite. Apache Data Lakehouse Weekly · 2026-08-26

    A shared conformance suite makes cross-engine Iceberg compatibility claims — Snowflake vs. Databricks vs. Trino — actually checkable rather than marketing, worth citing the next time a vendor claims full spec compliance.

AI-ready vs analytical-ready data

  1. 01
    Verizon taps Google's Agentic Data Cloud to unify data

    Verizon and Google Cloud announced an expanded partnership on 24 August under which Verizon will deploy Google's Agentic Data Cloud and Gemini Enterprise to unify data across the company as the foundation for building and deploying AI agents. CIO Dive · 2026-08-24

    A telco-scale customer treating data unification as the prerequisite step before agent rollout, not the agents themselves, is a template worth citing when pitching a readiness roadmap to a skeptical board.

  2. 02
    Databricks adds least-privilege table write grants

    Databricks put INSERT, UPDATE and DELETE privileges into beta on 24 August as least-privilege alternatives to the blanket MODIFY grant, letting teams give write access to a table's data without also granting the ability to change its schema. Databricks Docs · 2026-08-24

    Finer-grained write grants close a real gap in the access-control story teams reach for when asked whether a table is safe to expose to an agent — worth flagging to whoever owns the next access review.

  3. 03
    Databricks brings Genie One to the desktop

    Databricks shipped a native macOS desktop app for Genie One in beta on 25 August, giving business users the same natural-language chat over Unity Catalog tables and Genie Agents as the web experience, plus desktop conveniences like an unread-activity badge. Databricks Docs · 2026-08-25

    Packaging natural-language query as a native app rather than a browser tab is a small but real signal that vendors are betting business users, not just analysts, become the primary consumers of AI-ready data.

Data domain ownership and data mesh chart a path to AI-ready data

A data mesh treats each business domain — billing, say, or logistics — as the owner and publisher of its own data, the way a product team owns a product, instead of funnelling every table through one central data team that can't keep up. Each domain team becomes responsible for making its data discoverable, documented and trustworthy for whoever needs it next, a model included. The idea isn't a new tool — it's a change in who is accountable for a dataset being good enough to hand to an AI system, rather than assuming a central pipeline will clean it up eventually.

For the roadmap Before buying another catalog or quality tool, it's worth asking whether the real gap is ownership — nobody accountable for a given dataset being AI-ready — since no tool fixes that on its own.
