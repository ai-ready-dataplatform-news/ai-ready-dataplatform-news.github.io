    Trust3 AI syncs access policies across Databricks, Snowflake and OneLake

    Trust3 AI will automatically sync row- and column-level security policies from Databricks and Snowflake into Microsoft OneLake Security, so agents and Power BI inherit the source platform's rules. TechNode / press release · 2026-09-30

    A platform PM running more than one engine has a way to avoid maintaining a second set of access rules for agents.

  2. 02
    Nvidia launches open platform to quarantine rogue AI agents

    Nvidia's Open Agent Safety Platform pairs an open-source runtime, OpenShell, with BlueField-4-based Sentry, which it says can quarantine an agent that crosses its boundaries within milliseconds; more than 100 organisations are partners. Euronews · 2026-09-28

    Agent runtime limits are becoming a layer beneath data-platform grants, which changes where a governance requirement gets written.

Governing AI Agents

An AI agent that can read your data can also read things it should not. This short course treats an agent like a new employee: give it a role, give it only the tables it needs, record what it does, and have a way to switch it off. It shows this on a data-analysis agent using Unity Catalog permissions, with four ideas: lifecycle, risk, security and observability.

For the roadmap It gives a platform PM a checklist for the agent-access requirements to write into the roadmap: least-privilege grants and an audit trail per agent.
