AI news for Data Products and Data Platforms

  1. 01
    Databricks acquires Row Zero for governed spreadsheets

    Databricks acquired spreadsheet startup Row Zero on September 24 and is folding it into Genie, giving finance and ops teams a governed spreadsheet interface over live, permissioned data instead of an exported copy. TechCrunch · 2026-09-24

    Another build-vs-buy data point for the catalog and observability stack: platform vendors are absorbing the last mile of analytical consumption rather than leaving it to spreadsheets exported outside governance.

  2. 02
    Anthropic and OpenAI cut frontier model token prices

    Claude Opus 5.5 and OpenAI's GPT-6 Sol and Luna launched within about 90 minutes of each other on September 22, cutting frontier and mid-tier token prices 20-50% — GPT-6 Sol at $2/$10 per million tokens against Opus 5.5's $4/$20. SiliconANGLE · 2026-09-22

    Feeds the cost-per-governed-dataset and platform FinOps case directly: inference cost is now falling faster than platform compute cost, which shifts the economics of conversational access — like the Genie-to-Claude pilot — relative to the pipeline work underneath it.

  3. 03
    CLARA Analytics launches agentic AI for claims

    CLARA Analytics launched Agentic Intelligence on September 22, an AI workforce that runs casualty and workers'-comp claims from first notice of loss through resolution while adjusters keep the final decision. Reinsurance News · 2026-09-22

    A concrete case of governed AI agents operating inside a regulated claims workflow with a human still accountable for the outcome — the same shape the platform's own gold-layer-to-agent question has to answer.

AI-ready vs analytical-ready data

  1. 01
    Amundsen, the open-source data catalog, is archived

    The LF AI & Data governing board archived the Amundsen project on September 10 after it stalled — the code stays available under Apache-2.0 but the repo is now read-only, with no further releases or security patches. GitHub / LF AI & Data · 2026-09-10

    One open metadata standard loses momentum while governed commercial catalogs absorb the same job — evidence for the buy-vs-build catalog and observability decision rather than betting a roadmap on community-maintained metadata tooling.

  2. 02
    BigLake catalog adds GA support for Iceberg REST Catalog

    Google's BigLake metastore reached general availability for the Apache Iceberg REST Catalog spec, giving BigLake Iceberg tables the same lineage, profiling, data-quality and discovery coverage as native BigQuery data, with federated reads from Databricks Unity, AWS Glue and Snowflake Horizon catalogs still in preview. Google Cloud (Knowledge Catalog release notes) · 2026-09-24

    Bears directly on the buy-vs-build catalog decision and on cross-platform lineage for a stack that already spans Unity Catalog and Redshift — one governance layer reading Iceberg tables across vendors is the alternative to maintaining that mapping by hand.

podcast · Experiencing Data w/ Brian T. O'Neill
AI for BI: preparing analytics to work with LLMs

A knowledge graph is a map of what a business's data actually means and how the pieces connect — this customer record is that account, revenue means net-of-returns, a claim belongs to a policy. A dashboard works without one because a person built the query and already knew those connections. An LLM doesn't: ask it what churn was last quarter and it will guess at a join and a definition, often wrong in a way that sounds completely confident. A knowledge graph, or a semantic layer doing the same job, is what lets the model look up the real definition instead of guessing one.

For the roadmap Speaks directly to whether a governed gold layer can serve analytical and agentic consumption from one source without the two paths diverging — the decision live this quarter. The argument here is that the semantic layer, not the model, is what has to carry that consistency.
