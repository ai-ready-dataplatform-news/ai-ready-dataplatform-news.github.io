AI news for Enterprise Data Platform Product Management

  1. 01
    Pipeline ran clean while numbers were 40% wrong

    InMarket's ad-event pipeline logged zero errors for days while a silent upstream field rename cut audience counts by 40%, caught only when a client's campaign underperformed. VentureBeat · 2026-09-09

    Job-success monitoring proves nothing about correctness — a governed gold layer needs a semantic check on the numbers themselves, not just a green pipeline run.

  2. 02
    Databricks enforces default-deny workspace access

    As of 14 September, every Databricks workspace grants entitlements explicitly per principal instead of inheriting them from the users system group, moving from default-allow to explicit grant. Databricks documentation · 2026-09-14

    Any onboarding script or automation that relied on inherited access loses it silently unless it was migrated first — worth an audit before it shows up as a support ticket.

  3. 03
    dbt Projects on Snowflake ships Slim CI, GA

    Slim CI, defer-to-production and failed-run recovery are now generally available for dbt Projects on Snowflake, reusing production dbt artifacts instead of a separate artifact store. Snowflake documentation · 2026-09-10

    Cuts CI/CD cost and recovery time for teams running dbt natively on a warehouse — a concrete data point in the buy-vs-build case for the transformation layer.

AI-ready vs analytical-ready data

video · Chad Sanderson
Data Contracts: The Rise of Modern Data Management

A data contract is a formal agreement between whoever produces a piece of data and whoever consumes it: what fields exist, what they mean, and what happens before either one changes. Instead of an analyst discovering a broken dashboard after the fact, the producer has to check with consumers before a change ships — the way an API versioning policy protects the people calling it.

For the roadmap Reframes 'data quality' as an interface problem rather than a testing problem — the case for treating the gold layer's schema as a versioned contract with named consumers, not just a governed table.
